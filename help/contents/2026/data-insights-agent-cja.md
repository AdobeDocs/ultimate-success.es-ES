# Puesta en funcionamiento de Adobe Data Insights Agent en CJA

Aprenda a convertir Adobe Data Insights Agent en un flujo de trabajo práctico y diario dentro de Customer Journey Analytics. Esta sesión muestra cómo los equipos pueden utilizar la petición de datos en lenguaje natural para acelerar el análisis, habilitar las perspectivas de autoservicio y reducir la dependencia en la creación de informes manual. Si desea mejorar el tiempo de respuesta a insight y escalar la toma de decisiones basada en datos en toda la organización, esto es algo que no debe perderse.
