# Creación de una estrategia de experiencia del cliente para maximizar el valor de AJO

En esta sesión se analiza cómo maximizar el valor de Adobe Journey Optimizer anclando la activación en una estrategia de experiencia del cliente clara, traduciéndola en casos de uso medibles y ejecutándola a través de procesos coordinados e interfuncionales. Entre las principales ventajas se incluyen una mayor claridad estratégica, una mejor alineación con las prioridades empresariales, una personalización más impactante, una mayor eficiencia operativa y un marco escalable para ofrecer resultados de cliente coherentes y mensurables.
