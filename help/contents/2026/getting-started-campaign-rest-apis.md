# Inicie la integración: Introducción a las API de REST de Campaign

Las API de REST de Campaign ofrecen una forma optimizada de crear interacciones valiosas con los clientes mediante la vinculación de momentos de participación con acciones de marketing o servicio. Esta sesión forma parte de la serie de Ultimate Success y está diseñada para ayudarle a comprender y utilizar estas API de forma eficaz.

## Principales conclusiones

- Aprenda a traducir un caso de uso en una historia de integración pequeña y comprobable.
- Comprenda dónde crean valor las API y dónde pueden no ser la herramienta correcta.
- Obtenga información sobre cómo crear formas de solicitud, establecer protecciones y establecer rutas a la producción.

## Información general

Las API de REST de Adobe Campaign no son solo herramientas, sino una puerta de enlace para crear interacciones inmediatas y personalizadas con los clientes. Estas API le permiten lo siguiente:

- Almacene en déclencheur acciones específicas basadas en momentos del cliente, como enviar correos electrónicos de confirmación o actualizar las preferencias de usuario.
- Permite una integración perfecta con otras aplicaciones, incluidos Adobe y sistemas externos.
- Admitir casos de uso impulsados por eventos y de baja latencia, como notificaciones de carros de compras abandonados, correos electrónicos de bienvenida y confirmaciones transaccionales.

## Agenda

1. **Descripción general de la empresa:**
   - Conceptos estratégicos de las API de REST.
   - Identificación de momentos del cliente para la utilización de API.
2. **Datos técnicos:**
   - Configuración y autenticación de puntos finales de API.
   - Configuración de la autenticación IMS y proyectos de Developer Console.
   - Explicación de la selección de puntos finales y personalización de carga útil.
3. **Demostración:**
   - Configuración de tipos de eventos y plantillas en Adobe Campaign.
   - Uso de Postman para llamadas a la API de SOAP y REST.
   - Ejemplos prácticos de llamadas de API y sus resultados.
